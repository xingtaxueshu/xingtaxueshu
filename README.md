# 星塔学术 · StarTower Academic

We build practical AI workflows for academic research, for **graduate students and researchers in the humanities and social sciences**.
面向人文社科研究生与研究者的 AI 学术工作流：开源 Agent Skills，由研究者自己做判断，AI 做研究助理。

Our focus is narrow on purpose: literature reviews, research design, methodology reasoning, and writing systems that keep the researcher's judgment in charge.

## Featured Projects

### [xingta-polish-en](https://github.com/xingtaxueshu/xingta-polish-en) · 英文学术润色

A fidelity-first agent skill for polishing the English of academic paragraphs: it changes language only, never arguments, data, citations or conclusions, and flags anything doubtful for the author. Ships with a preservation audit and a checking script. The bundled evaluation is a same-model self-evaluation on self-written paragraphs, not a blind review by real authors.

面向中文人文社科作者的保真优先英文润色 Skill：只改语言，不改论点、数据、引文、结论。

### [literature-review-skills](https://github.com/xingtaxueshu/literature-review-skills) · 文献综述

Five open agent skills for writing stronger literature reviews:

1. refine a broad topic into a real review question;
2. decompose the question into review modules;
3. compare research methods by what they can and cannot answer;
4. map conflicting findings without forcing fake agreement;
5. locate a concrete and defensible research gap.

Designed for Claude Code and Codex users, but the workflow can also be used without any AI tool. These are early versions without a systematic evaluation; please verify every citation yourself.

## What We Work On

- **Literature review workflows**: question refinement, review modules, contradiction mapping, and research-gap discovery.
- **Academic writing systems**: reusable skills and prompts that help researchers organize evidence instead of generating unsupported prose.
- **Research-method tooling**: small agent workflows for method comparison, proposal logic, and structured reading.
- **AI for social science research**: practical experiments with Claude Code, Codex, and agent skills.
